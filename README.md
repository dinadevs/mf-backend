# Sistema de Gerenciamento de Veículos  
vehicle-manager-aspnet-beginner

📘 **Projeto acadêmico desenvolvido na disciplina _Microfundamento: Desenvolvimento Web Back-End_ da PUC Minas.**

O objetivo foi aplicar os principais conceitos e tecnologias do **desenvolvimento Web Back-End**, utilizando **ASP.NET Core MVC** para construir uma aplicação completa, com CRUDs funcionais, autenticação, autorização, persistência de dados e banco de dados relacional.

---

## 🧩 About

O sistema web que permite o **cadastro de veículos**, o **registro de consumo de combustível** e o **gerenciamento de usuários** com diferentes níveis de acesso (usuário e administrador).
